# 🎵 Music Player

A modern and responsive Music Player built using **HTML, CSS, and JavaScript**. It features synchronized lyrics, a beautiful glassmorphism UI, keyboard shortcuts, and a smooth music listening experience.

## ✨ Features

- 🎶 Play / Pause Music
- ⏮ Previous & ⏭ Next Song
- 📜 Real-time Synchronized Lyrics
- 🎚 Song Progress Bar (Seek)
- 🔊 Volume Control
- ⌨️ Keyboard Shortcuts
- 🌌 Dynamic Blurred Background
- 💿 Album Cover Updates
- 📱 Responsive Design
- 🎼 Equalizer Animation
- ✨ Glassmorphism UI

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| Space | Play / Pause |
| ← | Previous Song |
| → | Next Song |
| ↑ | Volume Up |
| ↓ | Volume Down |
